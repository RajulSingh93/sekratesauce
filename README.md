# SEKRATE SAUCE

Website for SEKRATE SAUCE, built with Next.js 16 (App Router) and TypeScript.

## Run it locally

You'll need Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

The site runs at http://localhost:3000.

`npm run build` makes a production build, `npm run start` serves it, and `npm run lint` checks the code.

## Where things live

Pages and layouts are in `app/`. Global styles are in `app/globals.css`, and each component keeps its own styles next to it as a CSS Module. Images and other static files go in `public/`.
